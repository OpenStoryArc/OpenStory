OpenStory · draft

Empower yourself with your own history

Twenty ways to point OpenStory at your own work — to know yourself, sense your team, and never lose what you've already figured out. Every prompt is distilled from how OpenStory actually gets used, and each opens a real report, charted from a live store.

How to use: paste any of these to your coding agent. They run against your OpenStory instance — via the MCP server or the REST API at localhost:3002. Swap anything in <angle brackets> for your specifics. Open the report under any prompt to see what it returns.
