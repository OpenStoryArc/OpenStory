# Arena v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Arena v1 — a control plane, sealed sandbox image, and compose stack that lets event participants register with a join code and get Claude Code + a private OpenStory in a gVisor-isolated, no-internet container, metered through LiteLLM.

**Architecture:** One new self-contained Rust package at `arena/` (NOT a member of the `rs/` workspace — Arena deploys separately and must never couple the observer's build). The `arena` binary is both the HTTP control plane (axum) and the operator CLI (clap). Sandboxes are Docker containers created via a `SandboxDriver` trait (`DockerDriver` in prod via bollard, `FakeDriver` in tests); each sandbox gets its own internal Docker network so users cannot reach each other. Caddy terminates TLS for `*.arena.<domain>` and asks the control plane's `/authz` endpoint before proxying anything.

**Tech Stack:** Rust (axum 0.8, tokio 1, rusqlite 0.35 bundled, clap 4, toml 0.8, chrono 0.4, reqwest 0.12 rustls — same versions as `rs/`), plus new deps: `bollard` (Docker API), `argon2` 0.5, `axum-extra` (signed cookies), `async-trait` 0.1, `rand` 0.8. Infra: Caddy 2 (with cloudflare DNS plugin), LiteLLM + Postgres 16, gVisor (`runsc`) on the host.

**Spec:** `docs/superpowers/specs/2026-08-25-arena-sealed-sandboxes-design.md`

## Global Constraints

- **Branch/PR:** all work on branch `feat/arena-v1` cut from fresh `origin/master` in an isolated worktree (`git worktree add ../openstory-wt-arena feat/arena-v1`). Never push to master; open a PR. Never merge without Max's explicit approval.
- **Dependency audit:** every NEW crate (`bollard`, `argon2`, `axum-extra`, `async-trait`, `rand`) gets `cargo audit` run after adding it (install `cargo-audit` if missing) and a one-line justification in the commit message. Pin the versions given here; if a pin no longer resolves, use the latest compatible and note it in the commit.
- **Versions (copy verbatim):** `axum = { version = "0.8" }`, `tokio = { version = "1", features = ["full"] }`, `rusqlite = { version = "0.35", features = ["bundled"] }`, `clap = { version = "4", features = ["derive", "env"] }`, `toml = "0.8"`, `chrono = { version = "0.4", features = ["serde"] }`, `reqwest = { version = "0.12", default-features = false, features = ["json", "rustls-tls"] }`, `anyhow = "1"`, `serde = { version = "1", features = ["derive"] }`, `serde_json = "1"`, `tower = { version = "0.5", features = ["util"] }`.
- **TDD:** every Rust behavior lands test-first. Test names read as behavior: `fn register_with_wrong_join_code_is_rejected()`. For config artifacts (Caddyfile, compose, Dockerfile) the "test" is the validation command given in the task.
- **No secrets in git:** `.env` files are gitignored; only `.env.example` with placeholders is committed. Never commit a real API key, master key, or cookie key.
- **Usernames are the identity thread:** container `sandbox-{username}`, volume `arena-home-{username}`, network `arena-sb-{username}`, subdomains `{username}.` and `{username}-story.`, LiteLLM key alias `{event}/{username}`. Any new code must keep these derivations in `naming.rs` (Task 2) — never inline the format strings elsewhere.
- **gVisor is Linux-only.** Local dev (macOS) runs sandboxes with the default runtime; `ARENA_DOCKER_RUNTIME=runsc` is set only on the deploy host. Tests must not assume `runsc` exists. Tests that need a Docker daemon are `#[ignore]` and run via `just arena-test-docker`.
- **Reserved usernames (exact list):** `arena`, `www`, `api`, `litellm`, `hub`, `caddy`, `admin`, `story`. Also reject any username ending in `-story`.

```rust
use serde::Deserialize;

#[derive(Debug, Clone, Deserialize)]
pub struct EventManifest {
    pub name: String,
    pub image: String,
    #[serde(default)]
    pub join_code: Option<String>,
    #[serde(default)]
    pub roster: Option<Vec<String>>,
    pub ttl_hours: u64,
    pub budget_usd: f64,
    #[serde(default = "default_true")]
    pub retain_jsonl: bool,
}

fn default_true() -> bool { true }

impl EventManifest {
    pub fn from_toml(s: &str) -> anyhow::Result<Self> {
        let m: EventManifest = toml::from_str(s)?;
        m.validate().map_err(|e| anyhow::anyhow!(e))?;
        Ok(m)
    }

    fn validate(&self) -> Result<(), String> {
        if self.name.is_empty()
            || !self.name.chars().all(|c| c.is_ascii_lowercase() || c.is_ascii_digit() || c == '-')
        {
            return Err(format!("event name must be [a-z0-9-]+, got {:?}", self.name));
        }
        match (&self.join_code, &self.roster) {
            (Some(_), Some(_)) => return Err("set join_code OR roster, not both".into()),
            (None, None) => return Err("one of join_code or roster is required".into()),
            _ => {}
        }
        if self.ttl_hours == 0 { return Err("ttl_hours must be >= 1".into()); }
        if self.budget_usd <= 0.0 { return Err("budget_usd must be > 0".into()); }
        Ok(())
    }
}
```

```rust
pub const RESERVED: &[&str] = &["arena", "www", "api", "litellm", "hub", "caddy", "admin", "story"];

pub fn validate_username(u: &str) -> Result<(), String> {
    let ok_len = (2..=31).contains(&u.len());
    let ok_first = u.chars().next().is_some_and(|c| c.is_ascii_lowercase() || c.is_ascii_digit());
    let ok_chars = u.chars().all(|c| c.is_ascii_lowercase() || c.is_ascii_digit() || c == '-');
    if !(ok_len && ok_first && ok_chars) {
        return Err("username must be 2-31 chars of [a-z0-9-], starting with a letter or digit".into());
    }
    if u.contains("--") || u.ends_with('-') {
        return Err("username must not contain '--' or end with '-'".into());
    }
    if RESERVED.contains(&u) { return Err(format!("{u:?} is reserved")); }
    if u.ends_with("-story") { return Err("usernames may not end in -story".into()); }
    Ok(())
}

pub fn container_name(u: &str) -> String { format!("sandbox-{u}") }
pub fn volume_name(u: &str) -> String { format!("arena-home-{u}") }
pub fn network_name(u: &str) -> String { format!("arena-sb-{u}") }
pub fn terminal_host(u: &str, base: &str) -> String { format!("{u}.{base}") }
pub fn story_host(u: &str, base: &str) -> String { format!("{u}-story.{base}") }
pub fn key_alias(event: &str, u: &str) -> String { format!("{event}/{u}") }
```

`create(spec)` sequence (each step idempotent — check-then-create):
1. Create network `naming::network_name(u)` with `internal: true`, labels `{"arena.user": u, "arena.event": event}`.
2. Connect `edge_container` and `litellm_container` to it (ignore "already connected" errors).
3. Create volume `naming::volume_name(u)` (skip if `docker volume inspect` finds it — a relaunch reuses `$HOME`).
4. Create container `naming::container_name(u)`:
   - image `spec.image`; runtime from config; network = the per-user network; hostname = username
   - env: `ANTHROPIC_API_KEY={spec.api_key}`, `ANTHROPIC_BASE_URL={litellm_url}`, `ARENA_USERNAME={u}`
   - labels: `arena.user`, `arena.event`, `arena.expires` (RFC3339)
   - HostConfig: `readonly_rootfs: true`, `cap_drop: ["ALL"]`, `security_opt: ["no-new-privileges"]`, tmpfs `/tmp`, binds `[{volume}:/home/dev]`, `nano_cpus = cpu_limit*1e9`, `memory = memory_bytes`, `restart_policy: unless-stopped`
   - no published ports (Caddy reaches it over the shared network)
5. Start it; return container id.

`destroy(username, keep_volume)`: stop+remove container (ignore 404), disconnect edge/litellm from the network and remove it (ignore 404/in-use races), remove volume unless `keep_volume`.

`is_running(id)`: inspect → `state.running` (404 → Ok(false)).
